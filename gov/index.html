회원가입, 15일 무료체험

국내 스토리지 솔루션 중

유일한 클라우드 서비스 보안인증 CSAP 획득

클라우다이크는 국내 스토리지 솔루션 중 유일하게 '클라우드서비스 보안인증(CSAP)'을
획득한 기업으로, 공공데이터의 안전한 보관과 효율적인 협업 환경을 제공합니다

 

기본 기능 안내

안전한 데이터 관리, 편리한 협업 기능

내부 데이터를 안전하게 보호하고 외부 데이터는 공유하는
공공 전용 클라우드 스토리지, 클라우다이크

 
 

기업 데이터 관리 솔루션

신속하고 안전한 데이터 저장

  • 특허 받은 실시간 동기화 기술
  • 안정적인 네이버 클라우드 서버

다중 기기 호환성

다양한 기기와 환경에서 접근

  • 웹, 모바일웹, 태블릿 환경 지원
  • 인터넷이 연결된 어디서든 접속

MS Office, PDF 및 HWP

파일 문서 뷰어 기본 제공

  • MS Office, HWP 뛰어난 호환성
  • 별도 라이센스 없이 팀원과 협업

간편한 파일 공유

클릭 한 번으로 파일 전송

  • 링크 하나로 파일 공유
  • 클릭 한번으로 다운로드
