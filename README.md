- `marketing/` : 현재 소개서·소개 영상 대본

## 실습 흐름
1. 개발팀(강사)이 홈페이지에 새 기능을 커밋합니다.
2. 마케팅팀(교육생)은 ChatGPT에서 `@feature-to-sales-kit 최신 커밋으로 소개서 리뉴얼하고 소개 영상 만들어줘`를 실행합니다.
3. 바뀐 코드가 소비자 언어로 바뀌고, 실제 화면 캡처가 들어간 새 소개서와 음성·자막 30초 영상이 나옵니다.

교육생은 GitHub 계정이 필요 없습니다. 저장소는 공개이며 읽기만 합니다.
분석 태그(GA·GTM·Clarity·메타 픽셀·네이버 로그·채널톡)는 실제 사이트 통계에 섞이지 않도록 제거했습니다.

## 파일 요청함 데모

`/app/file-requests/`에서 제목·설명·기한으로 요청을 만들고, 제출 링크에서 예시 파일을 선택하면 요청별 제출 건수와 파일 목록이 갱신됩니다. 기존 앱 사이드바와 전체 화면 목록에서 접근할 수 있습니다.

요청과 파일 메타데이터는 현재 브라우저의 localStorage에 저장됩니다. 링크에는 요청 정보가 들어 있어 다른 브라우저에서도 요청을 열 수 있지만, 제출 내역은 기기 간 동기화되지 않습니다. 실제 파일 업로드, 서버 저장, 인증·권한 관리는 포함하지 않는 교육용 데모입니다. 제출 건수는 제출된 예시 파일 수입니다. 기한은 브라우저 현지 날짜의 23:59까지입니다.

검증 방법:
1. `10월 프로젝트 산출물 제출` 요청에 설명과 미래 기한을 입력하고 생성합니다.
2. 목록에 요청명·기한·0건·진행 중이 표시되는지 확인합니다.
3. 제출 화면에서 파일 없이 제출하면 안내가 표시되는지 확인합니다.
4. 예시 파일 두 개를 제출하고 목록으로 돌아와 2건과 파일명을 확인합니다.
5. 새로고침 후 기록이 유지되고, 과거 기한으로 새 요청 생성이 차단되는지 확인합니다.
6. 마감된 요청은 제출 버튼이 비활성화됩니다. 잘못된 요청 링크와 저장 공간 오류는 오류 안내로 처리됩니다.
