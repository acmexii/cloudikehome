요금제 및 결제 문의

1. 결제는 어떻게 해야 하나요?

유료 결제는 1) 카드 결제와 2) 계좌이체 두 가지 방법이 있어요.

1) 카드결제: 카드 결제 방법 보러가기

2) 계좌이체: 고객센터 문의 (실시간 상담 바로가기)
(계좌이체 결제 시 세금계산서 발행이 가능해요.)

2. 카드 결제의 경우 영수증을 따로 받을 수 있나요?

네, 관리자 계정으로 로그인하시면 영수증을 따로 받을 수 있어요.
결제 영수증 다운로드 방법 보러가기

3. 요금제를 사용하다가 용량이 초과되면 어떻게 해야 하나요?

관리자 계정으로 로그인하면 대시보드에서 사용 용량과 남은 용량을 확인할 수 있어요.
용량을 초과하면 더 이상 업로드가 되지 않으니, 고객센터에 문의해 요금제를 업그레이드해 주세요.
요금제 변경 방법 바로가기

요금제 업그레이드는 기본적으로 만료일 이후 적용되지만, 즉시 적용을 원하시면 고객센터로 문의해 주세요.
(실시간 상담 바로가기)

4. 요금제에 기재된 파일 크기 무제한은 무슨 뜻인가요?

스탠다드(Standard 100GB) 요금제 이상을 사용하면 파일 크기와 상관없이 업로드 및 다운로드가 가능해요.

슬림(Slim 30GB) 요금제와 베이직(Basic 50GB) 요금제는 2GB 이하 파일만 업로드할 수 있어요.
2GB 이상의 파일은 분할해서 업로드해 주세요.

5. 요금제 별 제공되는 다운로드 트래픽 용량이 어떻게 되나요?

다운로드 트래픽은 요금제에 따라 제공 용량의 2.5배까지 사용할 수 있어요.
단, Trial(10GB) 무료체험 요금제와 슬림(Slim 30GB) 요금제는 제외돼요.

6. 사용 중에 언제든지 용량을 추가할 수 있나요?

네, 물론이에요!
용량은 100GB 단위로 업그레이드할 수 있으며, 기본적으로 만료일 이후 변경된 요금제가 적용돼요.
빠른 업그레이드를 원하시면 고객센터로 문의해 주세요. 남은 사용일은 일할 계산해 차액을 청구하며 즉시 적용해 드려요.
(실시간 상담 바로가기)

일반 문의

1. 서비스를 해지 하고 싶어요.

고객센터로 문의해 주세요.
※ 무료체험(Trial) 사용자는 만료일 이후 결제가 없으면 데이터가 자동 삭제되며, 추가 결제는 발생하지 않아요.
즉시 해지가 필요한 경우 고객센터로 문의해 주세요.
(실시간 상담 바로 가기)

2. 무료 체험에서는 일부 기능들이 제한되나요?

무료 체험은 15일 동안 제공되며, 10GB 용량과 최대 5명의 사용자를 등록할 수 있어요.
링크를 공유하면 다운로드 횟수가 3회로 제한돼요.

이 외에는 파일 공유, 문서 편집 유료 사용과 동일하게 서비스를 제공해 드려요.

3. 다운로드 트래픽이 초과되면 어떻게 되나요?

다운로드 트래픽을 초과하면 1GB당 270원(부가세 별도)의 추가 요금이 청구되며, 트래픽 초과로 서비스가 중단되지는 않아요.

4. 해외에서도 사용 가능한가요?

해외에서도 사용 가능하며, 인터넷 환경이 있는 곳이라면 어디에서나 이용할 수 있어요.
속도는 해외 인터넷 환경이나 개인 PC 환경에 따라 달라질 수 있어요.

5. 삭제된 파일을 복구 가능한가요?

파일이 삭제되면 1차적으로 휴지통에 보관되며, 웹 휴지통과 PC 휴지통(PC 클라이언트 사용 시)에서 복구할 수 있어요.
단, 휴지통을 비웠을 경우에는 파일 복구가 불가능해요.
파일 복구 방법 바로가기

6. 사용기간이 만료 후 기존의 업로드한 파일을 다운로드하고 싶은데 다운로드 기간은 어떻게 되나요?

사용 기간 만료 후, 만료일로부터 2주까지 다운로드가 가능하고, 2주 후에는 로그인이 차단돼요.

7. 폴더별 업로드 용량을 확인할 수 있을까요?

클다스트림이나 PC 클라이언트 사용자의 경우, 윈도우 탐색기에서 해당 폴더를 선택하고 오른쪽 마우스 버튼을 누른 후 "속성"을 선택하면, 해당 폴더 내 파일 갯수 및 용량 등을 확인할 수 있어요.

8. 하나의 아이디로 여러 대의 PC에서 로그인 및 사용이 가능한가요?

브라우저를 통한 웹 서비스는 가능하지만, 실사용자를 로그 기록상 추적할 수 없는 점을 고려해야 해요.
한편, 클다스트림이나 PC 클라이언트의 경우, 충돌을 피하기 위해 1대의 PC에 1개의 아이디를 사용하시는 걸 권장드려요. 예를 들어, 사무실 PC와 재택용 노트북을 사용하신다면, 아이디 2개를 각각 생성하여 구분해서 사용하시길 권장드려요.

9. 한국어 외에 외국어로 사용이 가능한가요?

웹 서비스는 한국어 외에도 영어, 일본어, 인도네시아어로 선택하여 사용하실 수 있어요.
외국인 협업자에게 링크를 제공하는 경우에도 링크 화면에서 언어 옵션을 변경하여 사용 가능합니다.

10. 폴더를 만들어서 공유하면 공유한 모든 사용자의 용량이 중복적으로 기업 사용 용량에 추가되나요?

폴더를 만들어서 공유한 분, 즉 소유자의 용량만 계산되며, 공유받은 사용자의 용량은 중복하여 계산되지 않아요.

웹 사용 문의

1. 웹과 PC 클라이언트에 특정 IP만 사용 가능하도록 할 수 있나요?

네, 가능해요.
※ 관리자 계정 로그인 → 설정 → 팀원 관리 → 사용자 선택 → 세부 권한 수정 → IP제한 체크 → 사용할 IP 입력 → 저장
IP 제한 방법 자세히 보러가기

2. 관리자가 사용자들의 활동 로그를 확인할 수 있나요?

관리자 계정으로 로그인 후 활동 로그 메뉴에서 본인의 로그는 물론, 사용자들의 파일 업로드, 이동, 삭제, 업데이트 등의 내역을 로그로 확인할 수 있어요.
※ 관리자 계정 로그인 → 설정 → 활동 로그
팀원 로그기록 확인 방법 바로가기

3. 클라우다이크를 지원하는 웹 브라우저는 어떤 것들이 있나요?

Safari 7 이상, Internet Explorer 10 이상, MAC OS 10.6 이상, 크롬은 모든 버전에서 지원해요.
저희 클라우다이크는 크롬에 최적화되어 있어, 더 빠르고 안정적으로 이용할 수 있어요.

4. 비밀번호 분실하여 로그인 창에서 비밀번호 찾기 기능을 사용하였는데 변경이 되지 않아요

비밀번호 변경 관련 이메일 인증이 원활하지 않은 경우, 관리자(최고 관리자 또는 중간 관리자)에게 문의하면, 관리자는 기존 비밀번호를 모르더라도 팀원 관리 메뉴에서 비밀번호를 변경해 줄 수 있어요.
※ 단, 최고 관리자 계정의 비밀번호를 분실한 경우, 고객센터로 문의하면 초기화가 가능합니다.

5. 공유 폴더와 기업 폴더의 차이점이 있나요?

공유 폴더는 폴더를 생성한 팀원(소유자)이 공유할 팀원을 선택하여 공유하고, 공유받은 팀원이 이를 수락하면 공유가 완료돼요.
만약 소유자가 누구와 공유해야 할지 정하기 어려운 경우, 폴더 소유자가 일단 기업 폴더로 지정해 놓으면, 모든 팀원이 해당 기업 폴더를 자신의 기업 문서함에서 확인할 수 있어요.
이후 팀원은 "요청 가능" 버튼을 클릭하여 소유자에게 공유를 요청하고, 소유자가 이를 수락하면 공유가 완성돼요. 즉, 공유 요청자와 수락자가 뒤바뀌는 차이점이 있어요.

6. 폴더별로 접근 권한 제한이나 비밀번호를 설정할 수 있나요?

폴더 소유자(폴더 생성자)로부터 공유받지 않은 팀원은 해당폴더의 존재여부 자체를 알 수 없으므로 별도의 접근권한 제한이나 비밀번호 설정 없이도 폴더접근 관리가 가능해요.

7. 관리자(최고관리자/중간관리자)는 모든 폴더를 볼 수 있나요?

관리자는 기업 계정 관리, 팀원 생성 및 팀원 권한 제한, 로그 활동을 통한 모니터링, 결제 업무 등 관리적인 업무를 수행하지만, 본인이 공유받지 않은 폴더는 볼 수 없어요.
일반 사용자는 폴더의 생성자(소유자)로서 공유 권한이 있어요. 즉, 관리자와 폴더 소유자는 별개의 개념이에요.

8. 공유 받은 팀원이 파일을 수정, 삭제를 하지 못하도록 할 수 있나요?

폴더 공유 시 다운로드 전용으로 공유하면 읽기 전용으로 공유가 돼요. 이 경우 열람과 다운로드는 가능하지만, 수정이나 삭제는 불가해요.

9. 폴더를 소유한 팀원이 퇴사하였는데 해당 팀원의 아이디를 변경하여 사용이 가능한가요?

아이디는 고유한 정보로서 변경이 불가능해요.
퇴사로 인한 계정/폴더의 관리 문제는 고객센터로 문의해 주세요.

10. 불필요한 파일들을 삭제했는데도 사용 용량이 줄지 않아요

파일이 삭제되면 해당 파일은 폴더 소유자의 웹 휴지통으로 들어가요. 확실히 삭제해도 되는 파일은 웹 휴지통에서 삭제해야 용량에 반영돼요.
삭제된 데이터의 크기가 클 경우, 웹 휴지통에서 삭제한 후에도 대시보드 용량 화면에 반영되는 데 시간이 다소 소요될 수 있어요. 이 경우 F5(새로 고침) 버튼을 눌러 최신화할 수 있어요.

11. 업로드와 다운로드가 모두 가능한 링크 기능이 있나요?

링크는 업로드 또는 다운로드 기능 중에서 선택하여 사용이 가능해요.
업로드/다운로드가 가능하게 하려면 아이디(팀원)를 생성한 후 해당 폴더를 공유하여 사용해야 해요.

12. 웹 로그인 시 다른 팀원 계정으로 로그인 돼요.

기존에 로그인 기록이 남아 있어 발생하는 현상이에요.
좌측 하단의 로그아웃 아이콘을 통해 로그아웃한 뒤, 다시 로그인해 주세요.

13. 공유하고자 하는 폴더를 공유하면 상위/하위 폴더에 이미 공유가 되어 있다는 메시지 나오며, 공유가 되지 않아요.

동일 경로 상에 2개의 공유는 허용되지 않아요.
이 경우, 해당 폴더의 상위 또는 하위 경로상에 이미 공유된 폴더가 존재하는 경우입니다. 별도의 공유가 필요하다면 새로운 최상위 폴더를 생성한 후 공유를 진행해 주세요.

14. 파일을 실수로 수정하여 저장하였는데 수정전 상태로 돌아갈 수 있나요?

웹 서비스에서 해당 파일을 열고 버저닝 기능(우측 상단 시계 모양 아이콘)을 사용하면, 수정하여 저장한 기록이 보여요. 여기서 이전 버전으로 미리 보기 또는 다운로드할 수 있습니다.
단, 파일명 자체가 변경되면 해당 파일의 버저닝 기록이 남지 않아요.

15. 관리자에게 특정 사용자의 트래픽, 다운로드, 링크가 일정 수준을 초과하였다는 알림 (왼쪽 하단 종 모양 아이콘)이 왔는데, 사용상 문제가 없는 것일까요?

관리자에게 참고 및 유의사항으로 알림이 가는 것이며, 사용상에는 문제가 없어요.

16. 사용자가 폴더를 마음대로 생성하지 못하도록 할 수 있을까요?

관리자(최고 관리자/중간 관리자)는 "기업 설정" 메뉴 → "기업 보안 설정" 메뉴에서 "관리자만 폴더 생성 허용"을 활성화하면, 관리자에게만 폴더 생성이 허용돼요.

PC클라이언트 문의

1. 폴더를 공유 받고 수락을 하였는데도 동기화 폴더에서도 폴더가 보이지 않아요.

화면 우측 하단의 숨겨진 아이콘 표시를 클릭한 후, PC 클라이언트 아이콘을 오른쪽 마우스 버튼으로 클릭하고, "설정" → "동기화 폴더 선택"을 선택해 주세요.
체크되지 않은 해당 폴더를 체크한 후, 하단에 있는 "변경 사항 적용"을 누르면 동기화가 진행돼요. 최초 동기화 이후 새롭게 공유받은 폴더는 이 과정을 거쳐야 동기화돼요.

2. PC클라이언트 사용 시 하드디스크에 저장되어 있는 공유된 폴더를 삭제해도 되나요?

공유된 폴더를 삭제하면 다른 공유받은 사용자들에게도 삭제가 진행돼요. 원본 자체가 삭제되기 때문에 전체적으로 삭제가 필요한 파일이라면 삭제해도 무방하지만, 내 PC에서만 삭제하려면 공유 해제 또는 동기화 폴더 목록에서 제외해야 해요.

  • 재동기화 또는 하드디스크에서 동기화 폴더를 전체 삭제하려면 반드시 PC 클라이언트 프로그램을 종료하고, 제어판에서 앱을 삭제한 후 동기화 폴더를 삭제해야 웹 서버에 저장된 원본이 안전하게 유지돼요.
